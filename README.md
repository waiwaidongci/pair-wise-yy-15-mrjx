# hxyfront-62014 训放费用分摊台

源提示词编号：9

面向赛鸽棚的训放费用分摊工具，替代群里接龙记账：

- 每场登记车辆、油费、路桥费和放飞费，按实际装笼羽数平摊；
- 出发前退出的鸽子不计费，未归巢照样承担费用；
- 财务确认后账单锁定；锁定后再改训放距离或装笼名单，需重新核算生成新版账单，旧版自动归档留存；
- 鸽主可按足环号、日期区间、支付状态（全部/未支付/已支付）查询每笔费用，可勾选查看旧版账单；
- 数据通过 localStorage 本地持久化。

## 业务文件结构

- `src/domain/billing.ts`：费用规则——费用合计、装笼状态、平摊试算、账单快照、锁定后差异判定；
- `src/domain/archive.ts`：存档——账单版本锁定/旧版留存、支付状态继承与登记、费用查询、本地持久化及演示数据；
- `src/App.tsx`：页面操作——场次登记、装笼名单管理、财务确认、重新核算、账单存档与查询界面。

## 技术栈

React + Vite + TypeScript
