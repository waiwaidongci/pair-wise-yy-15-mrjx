# 训放费用分摊台 · 赛鸽训放

面向赛鸽棚的训放开销分摊与记账前端，替代群里接龙、月底算不清的老办法。

## 记账规则

- 每场训放登记：日期、放飞地点、**训放距离、车辆、油费、路桥费、放飞费**和装笼名单（足环号 + 鸽主）。
- **平摊口径**：油费 + 路桥费 + 放飞费合计，按实际装笼羽数均分；除不尽的分币按足环排序补给前几只，合计一分不差。
- **出发前退出不计费**；**未归巢照样承担**（名单里用状态区分，锁定账单快照保留该状态）。
- **财务确认后账单锁定**，锁定后不能直接改数。
- 锁定后再改训放距离或装笼名单：先「申请改单」→ 修改后「重新核算并锁定新版」，**旧版账单原样留档**，版本间附差异说明（距离/费用变动、新增移出名单、每羽分摊变化）。
- 鸽主可按**足环号、鸽主、训放日期、支付状态**查每笔费用，可勾选连存档旧版一起查，结果可导出 CSV。
- 数据存浏览器 localStorage，不上传服务器；页脚可一键恢复演示数据（含一场已重算过两版的示例）。

## 业务文件划分

| 文件 | 职责 |
| --- | --- |
| `src/business/feeRules.ts` | **费用规则**：计费状态口径、平摊算法（含分币处理）、锁定前校验、账单快照生成与版本差异描述 |
| `src/business/archive.ts` | **存档**：localStorage 持久化、种子数据、账单版本留存、费用查询（足环/日期/支付状态/旧版）、CSV 导出 |
| `src/business/pageOps.ts` | **页面操作**：场次登记、名单编辑、财务确认锁定、申请改单重算、收款登记、删除草稿、概览指标（`useFeeDesk`） |

另：`src/types.ts` 为数据模型，`src/App.tsx` 为页面组装（场次编辑器、分摊明细、账单存档、鸽主查账台）。
